# Imagens dos produtos — créditos e licenças

Fotos usadas no catálogo do AgapeApp (recortadas em quadrado e reduzidas para até 600×600).
Todas têm licença livre que permite uso, inclusive comercial, desde que o autor seja creditado
(CC BY / CC BY-SA) — ou nenhuma exigência (CC0 / domínio público). Fontes: Wikimedia Commons e
Openverse (Flickr). Imagens de marcas (Coca-Cola, Fanta, Sprite, Guaraná Antarctica) mostram apenas
o produto; as marcas pertencem aos seus donos.

Os arquivos com nome legível (ex.: `coxinha.jpg`) são as imagens-base do projeto: a API nunca os
apaga. As imagens enviadas pelo app ganham nome GUID e substituem a base só naquele produto.
